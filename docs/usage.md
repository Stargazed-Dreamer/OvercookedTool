# 使用手册（Usage）

本文面向最终用户，说明如何安装、启动并使用「胡闹厨房存档管理器（OvercookedTool）」管理《胡闹厨房》（Overcooked! 2 / Overcooked! All You Can Eat）存档。

## 1. 安装与启动

1. 从发行包解压到任意目录。
2. 双击运行 `OvercookedTool.App.exe`。
3. 首次启动时，工具会自动运行 Unity 设备标识 Harness 采集本机标识，完成后状态栏会提示设备标识已保存。该标识用于后续自动密钥探测，无需手动干预。
4. 主窗口出现后，顶部为标签页栏（默认含一个 `+` 标签用于导入），下方为当前存档包的展示区。

> 运行需要 .NET 9 桌面运行时。若提示缺失运行时，请安装 [.NET Desktop Runtime 9.x](https://dotnet.microsoft.com/zh-cn/download/dotnet/9.0)。

## 2. 导入存档包

- **点击导入**：点击主界面空白区域（提示“点击此空白区域导入存档包”），在弹出的“导入存档包”窗口中输入或浏览选择存档目录，点击“导入”。
- **拖拽导入**：将存档目录直接拖入主窗口，工具会自动识别。
- **自动检测候选**：若选择的目录本身不是存档包，工具会向下递归（最多 3 层、120 个目录）查找候选存档包；找到唯一候选时直接导入，多个候选时列出供选择。
- **最近路径**：导入过的路径会记录在设置中，便于快速重复导入。

导入后会出现一个以目录名命名的新标签页。

## 3. 识别结果说明

导入完成后，标签页会显示以下识别信息：

- **平台**：`Oc2`（OC2 二进制）、`AyceJson`（AYCE JSON）、`XboxBinary`（Xbox 二进制）、`SwitchJson`（Switch JSON）。
- **存档包版本**：`Oc2` 或 `Ayce`，由读取首个存档的 `AssistModeEnabled` 键判定。
- **密钥状态**：成功 / 失败，以及密钥来源（手动输入 / Unity 设备标识 / 目录名 / `steam_autocloud.vdf` 的 accountid / SteamID64 / 父目录数字 ID / Epic 常见密钥）。
- **好友号**：从 `steam_autocloud.vdf` 提取的 `accountid`。
- **存档卡片**：按分组（主线 `CoopSlot` / DLC / 自定义前缀）与档位展示，每张卡片显示档位、文件名与总星数。
- **冲突**：若同分组出现重复档位，会标记冲突。
- **待同步**：列出“未发现工具备份”或“源文件较新、备份待同步”的诊断信息（“未发现工具备份”只是提示尚未触发过备份，不代表导入失败）。

## 4. 手动输入密钥

若自动探测失败，可在标签页的密钥输入区手动输入密钥并确认。手动密钥会作为首选候选重新尝试解密。常见有效密钥包括：

- Steam 账户的 SteamID64（17 位数字，形如 `76561198xxxxxxxxx`）；
- 存档目录名本身（部分平台直接用目录名作密钥）；
- Unity 设备标识（首次启动已自动采集）；
- `steam_autocloud.vdf` 中的 `accountid`（32 位账户 ID）。

JSON 平台（AYCE / Switch）无需密钥。

## 5. 存档操作

选中一张存档卡片后，可执行以下操作（操作前都会自动备份）：

- **复制到目标包**：将当前存档复制到另一个存档包，自动按目标平台重命名并做版本转换（OC2 ↔ AYCE），历史备份一并复制过去。
- **移动到目标包**：同上，但移动后删除源文件（删除前再做一次“move-delete-source”备份），历史备份迁移到目标目录。
- **删除**：删除前自动备份，可在历史时间线恢复。
- **调整档位**：在同分组内左/右移动档位；目标档位被占用时会与相邻存档交换位置（交换前对双方各做一次备份）。
- **新建存档**：选择分组与档位，基于同分组模板存档创建新档，可选预设（“通关存档”会设置 `ScoreStars=4`、`Completed=True` 等；默认预设会重置为未完成）。

> 若复制/移动到与源同包同档位，工具会自动分配下一个空闲档位，避免覆盖自身。

## 6. 编辑存档

选中存档后点击“编辑存档”打开编辑器。提供三种编辑方式：

- **JSON 编辑器**：直接查看与编辑存档原始 JSON 文本，保存时按当前平台加密落盘（JSON 平台直接写文本）。
- **表格编辑器**：以表格形式列出关卡记录（`Level_*` 条目），可逐字段编辑关卡属性。
- **Meta 编辑器**：编辑 Meta 存档的条目。

保存前工具会自动对当前文件做“edit”备份；取消则不写入。

## 7. 备份与历史

- **自动备份**：所有写入型操作（编辑、复制/移动覆盖、删除、调整档位、新建、同步、冲突处理、恢复历史）在执行前都会把原文件复制到存档目录下的 `.overcookedtool-backup/`。
- **备份命名**：`{文件名}.{yyyyMMddHHmmssfff}.{原因}.bak`，原因标签如 `edit`、`delete`、`move-slot`、`move-overwrite-target`、`copy-overwrite-target`、`manual-backup`、`sync-restore`、`restore-history` 等。
- **保留数**：每个文件按时间倒序保留最近 N 份（默认 10，可在“设置”中调整 `MaxBackupPerSave`），超出部分自动删除。
- **历史时间线**：在存档上打开“历史时间线”（`SaveTimelineForm`），按时间倒序列出该存档的全部备份，显示时间、大小与原因；选择某条历史后可“恢复”到该版本（恢复前会对当前文件再做一次“restore-history”备份）。

## 8. 同步诊断

标签页的同步诊断区域汇总以下问题：

- **待同步**：源文件比最近备份更新（修改时间晚于备份 1 秒以上），建议执行“同步到源文件”或“批量备份待同步项”。
- **冲突**：同分组出现重复档位编号，可通过“冲突处理”选择保留源文件或恢复备份。
- **未发现工具备份**：尚未触发过任何自动备份，属于诊断信息而非错误。

可用操作：

- **同步到源文件**：对选中的存档，若备份较新则用备份覆盖源文件（覆盖前先备份当前源文件）；若无备份则创建基线备份。
- **批量备份**：对选中的待同步存档一次性创建“manual-backup”备份。
- **冲突处理**：对冲突项选择保留源文件（备份后保留现状）或恢复备份（用备份覆盖当前文件）。

## 9. 设置

通过“设置”菜单打开设置窗口，可配置：

- **自动检测**：导入时是否自动检测候选路径。
- **日志**：是否启用日志记录。
- **最近历史条数**：保留的最近路径数量上限（默认 20）。
- **备份数**：每个存档保留的备份份数上限（默认 10）。
- **日志保留天数**：日志文件保留天数，超过自动清理（0 表示永不清理，默认 30）。

设置保存在 `appsettings.json`。修改后保存生效，取消则放弃更改。

## 10. 关于与捐赠

- **关于**：通过“关于”菜单打开，展示应用信息（内容由 `about_content.json` 提供）。
- **捐赠**：通过“捐赠”菜单打开，展示收款码（`libcoffee.dll` 是收款码图片改后缀存储）。

## 11. 常见问题

### Q1：密钥探测失败怎么办？

依次尝试：

1. 在标签页手动输入密钥（SteamID64、目录名、`steam_autocloud.vdf` 的 `accountid` 等）。
2. 确认 `steam_autocloud.vdf` 与存档在同一目录。
3. 若是 Epic 版，工具会自动尝试 Epic 常见回退密钥。
4. 检查日志 `logs/overcookedtool-yyyyMMdd.log` 中的 `Loaded package` 行，确认平台与密钥来源。
5. JSON 平台（AYCE / Switch）无需密钥，若仍失败请确认文件确实是明文 JSON。

### Q2：操作前的自动备份在哪里找？

在存档所在目录下的 `.overcookedtool-backup/` 文件夹中，文件名形如 `CoopSlot_SaveFile_0.save.20260807143012500.edit.bak`。可在“历史时间线”中直接浏览与恢复，也可手动复制出来。

### Q3：OC2 与 AYCE 有什么区别？复制时会发生什么？

- **OC2**：Overcooked! 2，二进制加密存档，关卡数据不含 `FailedAttempts` 与 `AssistModeEnabled`。
- **AYCE**：Overcooked! All You Can Eat，JSON 明文存档，关卡数据含 `FailedAttempts`，且整体含 `AssistModeEnabled` 条目。

复制/移动到不同版本的目标包时，工具会自动转换：

- OC2 → AYCE：为每个 `Level_*` 补 `FailedAttempts="0"`，并在末尾新增 `AssistModeEnabled=false` 条目；文件名改 `.save` 为 `.json`。
- AYCE → OC2：移除 `FailedAttempts` 与 `AssistModeEnabled` 条目；文件名改 `.json` 为 `.save`。

转换前后都会按目标平台加密（OC2）或写明文（AYCE），并自动备份与迁移历史。

### Q4：直接对真实游戏存档目录操作安全吗？

工具会在每次写入前自动备份到 `.overcookedtool-backup/`，但建议先把整个存档包复制到临时目录再操作，避免误操作影响真实存档。端到端测试与只读检查不会写入真实存档目录。

### Q5：日志在哪里？

`{程序所在目录}/logs/overcookedtool-yyyyMMdd.log`，按天一个文件，超过保留天数（默认 30）自动清理。可在“设置”中关闭日志或调整保留天数。
